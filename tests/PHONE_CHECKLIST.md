# 実機スマホ確認チェックリスト(5h 版・初心者向け)

目的:5h 版の「町づくり」を、**本物のスマホ**で一通り動かして、困ることがないかを確かめます。
所要時間の目安:準備 15〜20 分 + 確認 40〜60 分(途中でやめても大丈夫です)。

> **この確認では、GitHub の設定・本番サイト・main ブランチには一切さわりません。** 公開設定を変える必要もありません。
> もし途中で「公開設定を変える必要がある」と感じる場面が来たら、そこで止めて Claude に聞いてください(**事前の承認が必要**です)。

---

## 0. 先に読んでください(本番のデータを守るために)
- スマホやブラウザの保存データは、**「アドレス(URL)ごと」に別々**になります。
  この確認は、**自分のパソコンのアドレス(`http://192.168.…:8000/`)** で開くので、本番サイトの保存データとは完全に別です。
- ⚠ **やってはいけないこと**
  - 本番のアドレス(いつもゲームを開いているアドレス)で 5h 版を試すこと。
  - 同じ GitHub アカウントの別リポジトリを GitHub Pages にして試すこと。**アカウント名までが同じアドレスだと、本番と同じ保存場所を共有してしまい、本番のデータが書き換わるおそれがあります。**
  - アドレスの末尾に `#vil` を付けること(これは開発用のテスト入口です。今回は使いません)。
- 途中でパソコンのアドレスが変わると(Wi-Fi をつなぎ直した等)、保存データは空に戻ります。壊れたわけではありません。**最初からやり直し**になります。

## 1. 準備(パソコン側・1 回だけ)
1. **Node.js** を入れます(入っていれば不要)。手順は `PACKAGE_LOCK_GUIDE.md` の「Node.js のインストール」と同じです。
2. フォルダを用意します。
   ```
   C:\work\luna5h\index.html                      ← 提出された 5h 版 index.html
   C:\work\luna5h\tests\phone\serve_for_phone.js  ← 提出された tests ZIP を C:\work\luna5h に展開
   C:\work\luna5h\tests\phone\start_phone_check.bat
   ```
3. `start_phone_check.bat` を**ダブルクリック**します。
   - 「Windows セキュリティの重要な警告」が出たら、**「プライベート ネットワーク」にだけチェック**を付けて「アクセスを許可する」を押します。(「パブリック ネットワーク」は許可しません)
   - 黒い画面に、次の 3 つが出ます。
     - 表示しているファイル
     - **SHA-256**(長い英数字): 提出報告の 5h 版の値と**同じか**、見比べます。違う場合は、ここで止めて Claude に知らせてください。
     - **スマホで開くアドレス** `http://192.168.…:8000/`
4. **スマホを、パソコンと同じ Wi-Fi** につなぎます(モバイル回線ではなく)。
5. スマホのブラウザ(Chrome か Safari)に、黒い画面に出たアドレスを入力して開きます。
   - 開けないとき: ① 同じ Wi-Fi か ② ファイアウォールの許可(手順 3)③ ゲスト用 Wi-Fi・学校/会社の Wi-Fi は別の機器と通信できないことがあります。
6. 画面が出たら、**画面の自動回転をオン**にして、スマホを**横向き**にします。

## 3. 終わったら
1. パソコンの黒い画面で **Ctrl+C** を押して、サーバーを止めます(「停止しました」と出ます)。確認が終わったら**必ず止めてください**。
2. このチェックリスト(✅/❌とメモ)と、❌ の写真を Claude に送ってください。
3. スマホに残ったテスト用のデータ(`192.168.…` のサイトのデータ)は、**本番に影響しません**。消さなくて大丈夫です。

## 4. 困ったとき
- 画面が固まった/何も出ない:ブラウザを更新 → それでも駄目ならスクリーンショットを撮って送る。
- 「まちの データが よめないよ」「いま ほぞんが できない」と出た:画面の文字をそのまま写真で送る(ここでデータを消す操作はしない)。
- どこまで進んだか分からなくなった:メモした番号まで書いて送れば大丈夫です。

## 5. この確認でできないこと(Claude の未確認事項)
- このチェックは、あなたの **1 台の機種・1 つのブラウザ**での確認です。機種や OS が違うと別の結果になることがあります。
- 長時間(何時間も放置したあと)の動き、通信が不安定なときの動きは、この手順では確認しません。
- 世界樹 Lv2 に必要な数(23)は設計上の値で、実機で数え間違いがあっても構いません。
