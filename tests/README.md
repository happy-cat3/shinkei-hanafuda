# tests/ — 町づくり(vil-core / vil-ui)の確認スクリプト

【状態】5f 版までは GitHub(`feature/vil-storage`)に保存済み。この README は 5g 版への更新(**未アップロード**。ユーザーが確認後に手動でアップロード)です。

## 目的
作業環境の入れ替えでテストが消えるのを防ぐため、確認スクリプトとその実行結果をリポジトリで管理する。

## 必要な環境
- Node.js 22 以上、`npm i`（playwright は **1.63.0 に固定**）、`npx playwright install chromium`
- `package-lock.json` は、5f 作成時に npm レジストリへ接続できず生成できていません。初回に `npm i` を実行すると作られます(作られたらコミットしてください)。
- Linux / macOS。ブラウザは Chromium(Playwright)。**実機のスマホでは未確認**。

## 実行方法
```
cd tests && npm i && npx playwright install chromium
# 今の index.html(リポジトリ直下)を確認
bash run_all.sh                       # 5e/主要動線(76項目) + 5f専用 + 5g専用
# 前の版と比べる(同じ操作で保存データ・文言が一致するか)
bash run_all.sh /path/to/前の版のindex.html   # 比較(22場面)と、前の版が seen つきデータを読めるかも確認
```
- 別の場所のファイルを確認するときは `INDEX=/path/to/index.html bash run_all.sh`
- 結果は `tests/results/run_日時.txt` に、対象のSHA-256・サイズ・node・playwright・chromium の版つきで保存される。
